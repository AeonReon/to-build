💡 New here? How this pool is meant to be used ▾

Four for today is the quick way in. Tap one, read it, and if it is alive either dig into it in a chat or leave it. Shuffle if none of them land.

The shelves below are the whole pool sorted by kind, so you can see which things sit next to each other. The long riffs at the top are the ones already thought through in detail. The rest are single cards — a pattern, enough to recognise, with a chat prompt ready.

Most of these will never be built. That is the point. The pool exists so that a free evening never starts from a blank page.
